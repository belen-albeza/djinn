# Contributing

**⚠️ PRs have been disabled** to avoid a flood of AI-generated code.

After the initial release, I will re-evaluate how to accept community-provided contributions.

## Commit messages

- 🔧 `:wrench:`: A config or set up change.
- ✨ `:sparkles:` An enhancement.
- 🎉 `:tada:` A new feature.
- 🐛 `:bug:` A bug fix.
- 📚 `:books:` A documentation change.
- ♻️ `:recycle:` A refactor.
- 💄 `:lipstick:` Cosmetic changes (code formatting, etc.).

Examples:

- `:tada: Implement ADD opcode`
- `:bug: Fix PUSH not incrementing the pc`
